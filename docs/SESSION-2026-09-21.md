## Tools / gotcha penting

- **Model GAK BISA liat gambar yang di-paste di chat** (`[Image 1]` = placeholder kosong). Tapi **bisa baca file gambar** lewat tool Read. Kalau user kirim screenshot, minta save jadi file (`/tmp/xxx.png`) baru kasih path-nya.
- Headless Chromium: `img.decode()` bisa hang di lazy-image dalam `display:none` (MobileStage). Jangan pernah `await` tanpa timeout. Race condition, bukan bug produk.
- Screenshot person kadang "hilang" di headless = paint flake (compositor race), bukan bug. Selalu croscek `naturalWidth` + opacity sebelum panik.
- Feedback protocol (`docs/PRD-ADDENDUM-OPencode.md` §4): user kasih `fix: [section] [elemen] [masalah] [koordinat]` → jawab before→after angka + re-screenshot.
- Dev server: `http://127.0.0.1:5199/`. Cek live: `curl -s -o /dev/null -w "%{http_code}" :5199/`.
- Python di env ini GAK ada playwright-nya → pakai Node (`node script.mjs`) dari cwd proyek (node_modules ada playwright).
- Tailwind 4: arbitrary variant `min-[1280px]:` / `max-[1535px]:` dipakai untuk breakpoint custom.
